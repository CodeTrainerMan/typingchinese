## Возможности

### Тренировка слов

- **Четыре режима**: сопровождение (видите иероглифы — вводите пинъинь), диктант (только на слух), самопроверка (дан пинъинь — воспроизведите слово) и письмо по значению (показан только перевод)
- **Три режима ввода**: полный пинъинь `zhongguo`, первые буквы `zg` или тоны `zhong1 guo2`
- **Два способа набора**: латинские буквы на английской клавиатуре с мгновенной проверкой каждой буквы, или иероглифы через китайский IME (Microsoft Pinyin и другие) с оценкой по слову целиком
- У каждого слова — пинъинь со знаками тона, китайское озвучивание и перевод
- Любое количество повторов; слово с ошибкой можно автоматически очистить и ввести заново

### Тренировка текстов

- Встроенные тексты от начального до среднего уровня (от коротких фраз до небольших притч)
- Добавьте свой текст: вставьте его и печатайте предложение за предложением
- Каждое предложение озвучивается по ходу набора: чтение, слух и письмо усиливают друг друга

### Ошибки, повторения, статистика

- Каждое слово с ошибкой автоматически попадает в тетрадь ошибок
- Повторения планируются алгоритмом **FSRS** (Free Spaced Repetition Scheduler); долю повторений в день можно настроить
- На странице статистики: цель на день, слов в день, время, точность и число нажатий

### Гибкая настройка

- Звуки клавиатуры и звуки набора, регулируются громкость и скорость речи
- Свои горячие клавиши: повтор звука (<kbd>Tab</kbd> / <kbd>F2</kbd>) и следующее слово (<kbd>Пробел</kbd> / <kbd>Enter</kbd>)
- Экранная виртуальная клавиатура, светлая / тёмная / системная тема
- **14 языков интерфейса**: интерфейс следует вашему выбору, а учебный контент всегда китайский

### Чисто и эффективно

- Современный интерфейс без рекламы
- Работает полностью в браузере: без аккаунта, без бэкенда, без обязательной регистрации
- Весь прогресс хранится локально в `localStorage`

### Словари

Встроенные: **Повседневные слова** (59), **Продвинутый словарь** (51), **Идиомы из четырёх иероглифов** (40).

Свой словарь: вставьте список или загрузите `.json` / `.csv` / `.txt`. Одна запись на строку, пинъинь строится автоматически:

```
中国,国家名称
旅行 lv you
安静=没有声音
```

Готовый пример — `sample-words.csv`.

## Запуск локально

Проект сделан на Next.js, нужен Node.js 18 или новее.

```bash
git clone https://github.com/CodeTrainerMan/typingchinese.git
cd typingchinese/web
npm install
npm run dev
```

Откройте <http://localhost:3000>.

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить dev-сервер |
| `npm run build` | Продакшен-сборка |
| `npm run start` | Запустить собранное приложение |
| `npm run lint` | ESLint |
| `npm run gen:dict` | Пересоздать `public/dicts/*.json` из `scripts/seed-words.mjs` |

## Структура проекта

```
web/                    Приложение Next.js (единственный развёртываемый блок)
  src/app/              Маршруты: / (главная) /practice /article /dicts /wrong /stats /setting
  src/i18n/             Языковые пакеты (добавить язык: новый пакет + запись в LOCALES)
  src/lib/              Словари, пинъинь, TTS, планирование FSRS, локальное хранилище
  public/dicts/         Заранее собранные словари
  public/articles/      Встроенные тексты для тренировки
  scripts/              Исходный список слов и генератор словарей
sample-words.csv        Пример для импорта своего словаря
```

## Развёртывание

В корне репозитория нет `package.json`, поэтому при импорте проекта в Vercel (или другой сервис) **Root Directory должен быть `web`**. Остальное — стандартные настройки Next.js.

## Предложения и вклад

Проект молодой, функции постоянно добавляются. Идеи и сообщения об ошибках принимаются в `Issues`; если подход вам близок, присылайте `PR`.

- Добавить язык: создайте пакет в `src/i18n/messages/` и зарегистрируйте его в `src/i18n/index.tsx`
- Добавить слова: измените `scripts/seed-words.mjs` и выполните `npm run gen:dict`
