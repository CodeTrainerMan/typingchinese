## ฟีเจอร์

### ฝึกคำศัพท์

- **สี่โหมดการฝึก**: พิมพ์ตาม (เห็นอักษรจีน พิมพ์พินอิน), การเขียนตามคำบอก (ฟังอย่างเดียว), ทดสอบตนเอง (มีพินอิน ให้เขียนคำ) และเขียนจากความหมาย (แสดงเฉพาะคำแปล)
- **สามรูปแบบการพิมพ์**: พินอินเต็ม `zhongguo`, ตัวย่อ `zg` หรือวรรณยุกต์ `zhong1 guo2`
- **สองวิธีป้อนข้อมูล**: พิมพ์ตัวอักษรละตินบนคีย์บอร์ดภาษาอังกฤษพร้อมตรวจแก้ทีละตัวอักษร หรือพิมพ์อักษรจีนด้วย IME ภาษาจีน (Microsoft Pinyin และอื่น ๆ) แล้วตรวจเป็นคำ
- ทุกคำมีพินอินพร้อมเครื่องหมายวรรณยุกต์ เสียงพูดภาษาจีน และคำแปล
- ตั้งจำนวนรอบการทำซ้ำของแต่ละคำได้ และคำที่พิมพ์ผิดสามารถล้างแล้วพิมพ์ใหม่ได้อัตโนมัติ

### ฝึกบทความ

- มีบทความแบ่งระดับในตัว ตั้งแต่เริ่มต้นถึงระดับกลาง (จากประโยคสั้น ๆ ถึงนิทานสั้น ๆ)
- เพิ่มบทความของคุณเอง: วางข้อความแล้วพิมพ์ทีละประโยค
- แต่ละประโยคจะถูกอ่านออกเสียงขณะพิมพ์ ทำให้อ่าน ฟัง และเขียนเสริมกัน

### คำที่ผิด การทบทวน และสถิติ

- คำที่ทำผิดจะถูกเก็บเข้าสมุดคำผิดโดยอัตโนมัติ
- การทบทวนถูกจัดตารางด้วย **FSRS** (Free Spaced Repetition Scheduler) และปรับสัดส่วนการทบทวนต่อวันได้
- หน้าสถิติบันทึกเป้าหมายรายวัน จำนวนคำต่อวัน เวลาที่ใช้ ความแม่นยำ และจำนวนครั้งที่กดแป้นพิมพ์

### ปรับแต่งได้มาก

- เอฟเฟกต์เสียงคีย์บอร์ดและเสียงพิมพ์ ปรับระดับเสียงและความเร็วเสียงพูดได้
- กำหนดปุ่มลัดเองได้: ปุ่มฟังซ้ำ (<kbd>Tab</kbd> / <kbd>F2</kbd>) และปุ่มคำถัดไป (<kbd>Space</kbd> / <kbd>Enter</kbd>)
- คีย์บอร์ดเสมือนบนหน้าจอ ธีมสว่าง / มืด / ตามระบบ
- **14 ภาษาสำหรับอินเทอร์เฟซ**: อินเทอร์เฟซเปลี่ยนตามที่คุณเลือก ขณะที่เนื้อหาการเรียนเป็นภาษาจีนเสมอ

### เรียบง่ายและมีประสิทธิภาพ

- อินเทอร์เฟซทันสมัย ไม่มีโฆษณา
- ทำงานในเบราว์เซอร์ทั้งหมด: ไม่ต้องมีบัญชี ไม่ต้องมีแบ็กเอนด์ ไม่บังคับสมัครสมาชิก
- ความก้าวหน้าทั้งหมดถูกเก็บไว้ในเครื่องผ่าน `localStorage`

### พจนานุกรม

ที่มีให้: **คำใช้ในชีวิตประจำวัน** (59), **คำศัพท์ขั้นสูง** (51), **สำนวนสี่ตัวอักษร** (40)

นำเข้าของคุณเองได้: วางรายการหรืออัปโหลด `.json` / `.csv` / `.txt` หนึ่งรายการต่อบรรทัด ระบบสร้างพินอินให้อัตโนมัติ:

```
中国,国家名称
旅行 lv you
安静=没有声音
```

ดูตัวอย่างที่นำเข้าได้ทันทีที่ `sample-words.csv`

## รันบนเครื่อง

โปรเจกต์นี้สร้างด้วย Next.js ต้องใช้ Node.js 18 ขึ้นไป

```bash
git clone https://github.com/CodeTrainerMan/typingchinese.git
cd typingchinese/web
npm install
npm run dev
```

เปิด <http://localhost:3000>

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | เริ่มเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | บิลด์สำหรับ production |
| `npm run start` | รันผลลัพธ์ที่บิลด์แล้ว |
| `npm run lint` | ESLint |
| `npm run gen:dict` | สร้าง `public/dicts/*.json` ใหม่จาก `scripts/seed-words.mjs` |

## โครงสร้างโปรเจกต์

```
web/                    แอป Next.js (ส่วนเดียวที่ต้องดีพลอย)
  src/app/              เส้นทาง: / (หน้าแรก) /practice /article /dicts /wrong /stats /setting
  src/i18n/             แพ็กภาษา (เพิ่มภาษา: สร้างแพ็กใหม่ + เพิ่มหนึ่งรายการใน LOCALES)
  src/lib/              พจนานุกรม พินอิน TTS การจัดตาราง FSRS และที่เก็บข้อมูลในเครื่อง
  public/dicts/         พจนานุกรมที่สร้างไว้แล้ว
  public/articles/      บทความฝึกหัดในตัว
  scripts/              รายการคำตั้งต้นและตัวสร้างพจนานุกรม
sample-words.csv        ตัวอย่างสำหรับนำเข้าพจนานุกรมของคุณเอง
```

## การดีพลอย

รากของรีโพสิทอรีไม่มี `package.json` ดังนั้นเมื่อนำโปรเจกต์เข้า Vercel (หรือแพลตฟอร์มอื่น) **ต้องตั้งค่า Root Directory เป็น `web`** ส่วนที่เหลือใช้ค่าเริ่มต้นของ Next.js

## ข้อเสนอแนะและการมีส่วนร่วม

โปรเจกต์ยังใหม่อยู่และกำลังเพิ่มฟีเจอร์อย่างต่อเนื่อง ยินดีรับไอเดียและรายงานบั๊กผ่าน `Issues` หากคุณชอบแนวทางนี้ สามารถเปิด `PR` ได้เลย

- เพิ่มภาษา: สร้างแพ็กใน `src/i18n/messages/` แล้วลงทะเบียนใน `src/i18n/index.tsx`
- เพิ่มคำ: แก้ไข `scripts/seed-words.mjs` แล้วรัน `npm run gen:dict`
