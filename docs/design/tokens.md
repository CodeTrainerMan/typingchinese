# TypingChinese — 设计令牌（Design Tokens）

本文件是全站外观的**唯一事实来源**。改样式前先查这里；改这里等于改全站。
组件里只写语义类名（`bg-surface` / `text-brand` / `border-line` / `rounded-lg`），不写十六进制。

参考资料（分析原文）：
- `ref/analysis/DESIGN-notion.md` — **主干**：文档/工具型语言，暖纸底、hairline 卡片、多层微阴影、侧栏行、数据表、空状态
- `ref/analysis/DESIGN-apple.md` — 补充：间距节奏、44px 触控、2px 聚焦环、按压反馈
- `docs/brand/spec.md` — 品牌色约束：主灰 `#9AA0A8`、结构黑 `#17181A`、**强调蓝 `#2563EB`**、象牙底 `#F3F0E8`

**取舍原则**：Notion 做主干（色彩 / 圆角 / 阴影 / 层级），Apple 做补充（间距 / 触控 / 焦点 / 动效），两者冲突时见下表。

## 1. 两份参考冲突时的裁决

| 项 | Apple 说 | Notion 说 | 我们取 |
|---|---|---|---|
| 字重 500 | 禁用（400/600/700） | 按钮就是 500 | **取 Notion**：按钮/标签 500，标题 600，正文 400 |
| 卡片阴影 | 只有产品图可用 | 多层微阴影给卡片 | **取 Notion**（我们是卡片密集的工具界面） |
| 卡片圆角 | 18px | 12px | **取 Notion** 12px（18px 在密集界面太圆） |
| 正文 | 17px | 16px | **取 Notion** 16px |
| 强调色 | `#0066cc` | `#0075de` | **都不取**，用品牌规范 `#2563EB` |
| 底色 | 中性 `#f5f5f7` | 暖 `#f6f5f4` | **取 Notion** 暖调（长时间打字更护眼） |

## 2. 色彩

### 语义令牌（`globals.css` `:root`）

| 令牌 | 浅色值 | 用途 |
|---|---|---|
| `--bg` | `#f2f1ef` | 页面底（暖纸，比卡片略深，形成图底关系） |
| `--surface` | `#ffffff` | 卡片、面板 |
| `--surface-2` | `#f7f6f4` | 列表项、次级块 |
| `--solid` | `#ffffff` | 统计数字块、输入框 |
| `--hover` | `#eceae7` | 图标按钮 / 行 hover |
| `--active` | `#fdf6ec` | 选中、激活（浅橙，本产品自己的识别色，不用品牌蓝抢） |
| `--line` | `#e6e4e1` | 1px 分隔线、卡片描边 |
| `--ink` | `#2e2e2e` | 主文字（**不用纯黑**：汉字在纯黑上太硬） |
| `--ink-2` | `#5b5b5b` | 正文 |
| `--dim` | `#818181` | 辅助文字 |
| `--faint` | `#a8a29e` | 最弱层级：placeholder、元信息（对齐 Notion ink-faint） |
| `--brand` | `#2563eb` | 强调蓝：CTA、链接、进度、激活指示 |
| `--brand-soft` | `#eaf0ff` | 品牌底（胶囊/徽章） |
| `--purple` | `#ac6ed1` | 每日目标数字徽章（**唯一**允许的装饰色，见色彩纪律） |
| `--ok` / `--err` / `--warn` | `#16a34a` / `#dc2626` / `#d97706` | 语义色（Notion 营销站没有，打字练习必须要有对错反馈） |
| `--track` | `#e3e1dd` | 进度条轨道 |
| `--book` / `--book-line` | `#eceae6` / `#e2dfda` | 词库「书」封面底 / 书脊描边（仅 `ui/DictBook`） |

### 色彩纪律
- 强调蓝只用于**动作与状态**：CTA、链接、进度条、侧栏激活指示、可点文字 hover。不做装饰色块。
- 一屏之内结构色只有一个蓝；语义色（绿/红/橙）只报状态，不参与导航。
- 选中态用 `--active` 浅橙，与品牌蓝分离——蓝色留给"去做什么"，橙色表示"正在做什么"。
- `--purple` 只允许出现在首页「每日目标」数字徽章一处；其他任何地方想加装饰色，一律改用 `--brand-soft` 底 + `--brand` 文字。

## 3. 圆角

对齐 Notion 的 4 / 8 / 12 / 16 / 药丸（去掉 5px 与 6px 两档，Tailwind 默认 `rounded-md`=6px 不再使用）。

| 档位 | Tailwind | 值 | 用在哪 |
|---|---|---|---|
| xs | `rounded-sm` | 4px | 输入框、小标签、kbd 键位、色彩图例 |
| — | ~~`rounded-md`~~ | ~~6px~~ | **废弃**，一律并到 4 或 8 |
| md | `rounded-lg` | 8px | 按钮、实用按钮、侧栏行、日历格子 |
| lg | `rounded-xl` | 12px | 卡片、面板、弹层 |
| xl | `rounded-2xl` | 16px | 大容器、空状态框、Toast |
| pill | `rounded-full` | 9999px | 胶囊徽章、圆形图标按钮、进度条 |

Badge（"当前"这类）走 `rounded-sm` 4px，不用药丸——药丸只留给需要"可点/可选择"暗示的元素。

## 4. 阴影（Notion 的"几乎没有"策略）

不用单条重投影，用多层近透明叠加，卡片像"浮在纸面上"而不是"掉下来"。

```
--shadow-sm:   0 1px 2px rgba(0,0,0,0.06)
--shadow-card: rgba(0,0,0,0.01) 0 0.175px 1.041px,
               rgba(0,0,0,0.02) 0 0.8px 2.925px,
               rgba(0,0,0,0.027) 0 2.025px 7.847px,
               rgba(0,0,0,0.04) 0 4px 18px
--shadow-lg:   上述 4 层 + rgba(0,0,0,0.05) 0 23px 52px
```

- 默认卡片：**只有 hairline，不加阴影**。
- 需要抬起的卡片（浮动面板、Toast、弹层）：`--shadow-card`。
- 弹层 / 模态：`--shadow-lg`。
- 禁止自定义 `shadow-[0_10px_30px_...]` 这类硬投影。

## 5. 字重与字号

| 角色 | 字重 | 说明 |
|---|---|---|
| 正文、说明、表格内容 | 400 | 汉字正文绝不加粗 |
| 按钮文字、小标签、强调数字 | 500 | 按钮用 500 更柔和（Notion） |
| 标题（卡片标题、区块标题、列表名） | 600 | 汉字标题用 600，不用 700（700 易糊） |
| 数字（统计值、得分） | 700 | 拉丁数字 700 依然清晰，可作视觉锚点 |
| 展示用汉字（拼音区大字） | 400 | 宋体族本身笔画对比强，加粗会糊 |

基础字号：正文 16px（正文页）/ 14–15px（密集列表、表格）/ 12px（徽章、元信息）。

## 6. 间距与触控

- 8px 基准：**4 / 8 / 12 / 16 / 20 / 24 / 32**（20px 只作卡片内边距档，见下）。
- 4px 是唯一可用的半档（图标与文字、chip 内部等紧凑场景），**禁止再往下切 2 / 6 / 10 / 14px**（即 Tailwind 的 `*-0.5 / *-1.5 / *-2.5 / *-3.5` 一律并到 4 / 8 / 12 / 16）。
- 卡片内边距 20–24px（`p-5` / `p-6`）；列表行 12px 上下（`py-3`）；区块之间 24–32px（`gap-6` / `gap-8`）。
- Button 内边距横向 12–20px、纵向 8–12px；小号实用按钮 `px-2 py-1` 起。
- 宽度 / 高度 / 进度条粗细不受此约束（触控 44px、进度条 6–10px 属尺寸不属间距）。
- 触控目标：移动端最小 44×44（`min-h-11`），桌面可收到 36（`h-9`）。写法 `min-h-11 md:min-h-9`。
- 练习页三列统计里只有「用时」列可点（暂停 / 恢复计时），它按上面这条满足 44px；另两列用同样的 `min-h-11 md:min-h-0` 只为让分隔线对齐，不是触控目标。
- 窄屏兜底用 `max-[480px]:hidden` 这类任意值断点，不新增具名断点。
- 焦点：键盘可见焦点统一 2px 品牌蓝环 + 2px 偏移。
- 按压反馈：`transition-colors` 为主；按钮可加 `active:scale-[0.97]`，并在 `prefers-reduced-motion` 下关闭。

## 6.5 组件级规范

### 空状态（`ui/EmptyState.tsx`）
对齐 Notion `ex-empty-state-card`：居中 + 浅底圆形图标块 + 一句说明 + 可选行动。
- 页面级用 `variant="card"`（虚线 hairline 框 + 白底 + 上下 48px 留白）。
- 已经在 `Panel` 里时用 `variant="plain"`（不能再套一层卡片）。
- 说明文字走 `--faint`，主标题走 `--ink-2`，不要只用一句光秃秃的灰色 `<p>`。

### 数据表（词库条目表、错词表、统计表）
对齐 Notion `ex-data-table-cell`：
- 表头：`bg-surface2` + `text-xs`(12px) + `font-semibold`(600) + `text-dim`，表头行下一条 `border-b border-line`。
- 表体行：`border-t border-line` hairline，行高 `py-3`，数字列 `tabular-nums`。
- 不用斑马纹、不用外框之外的额外描边。

### 提示条 / Toast
`rounded-lg`(8px) + 语义色 10% 底 + 语义色 50% 描边（如 `border-ok/50 bg-ok/10 text-ok`），不要自定义投影。

## 7. 深色模式

跟随系统 + 手动覆盖（`data-theme`）。深色下：
- 底 `#202124` / 卡片 `#292a2d` / 次级块 `#35373a`；文字用 `rgba(255,255,255,0.82)` 而非纯白。
- 强调蓝换成 `#93ade3`（降饱和，避免在深底上刺眼）。
- 阴影在深色下加重透明度（`0.35` / `0.45`），否则看不出层级。

## 8. 禁止项

- 不在组件里写十六进制颜色，一律用语义令牌。
- 不用 `rounded-md`（6px）这一档。
- 不写自定义硬投影。
- 汉字标题不用 700，正文不用 500/600。
- 不把品牌蓝当背景大面积铺——它只做动作与状态。
- 不引入新的装饰色（如 Notion 的粉/青/橙贴纸色），语义色只有绿/红/橙三支，`--purple` 是历史遗留的唯一例外且仅限首页目标徽章。
