## Можливості

### Тренування слів

- **Чотири режими**: супровід (бачите ієрогліфи — вводите піньїнь), диктант (лише на слух), самоперевірка (дано піньїнь — відтворіть слово) і письмо за значенням (показано лише переклад)
- **Три режими вводу**: повний піньїнь `zhongguo`, перші літери `zg` або тони `zhong1 guo2`
- **Два способи набору**: латинські літери на англійській клавіатурі з миттєвою перевіркою кожної літери, або ієрогліфи через китайський IME (Microsoft Pinyin та інші) з оцінкою за слово
- У кожного слова — піньїнь зі знаками тону, китайське озвучення та переклад
- Будь-яка кількість повторів; слово з помилкою можна автоматично очистити й ввести заново

### Тренування текстів

- Вбудовані тексти від початкового до середнього рівня (від коротких фраз до невеликих притч)
- Додайте свій текст: вставте його та друкуйте речення за реченням
- Кожне речення озвучується під час набору: читання, слух і письмо підсилюють одне одного

### Помилки, повторення, статистика

- Кожне слово з помилкою автоматично потрапляє до зошита помилок
- Повторення плануються алгоритмом **FSRS** (Free Spaced Repetition Scheduler); частку повторень на день можна налаштувати
- На сторінці статистики: ціль на день, слів на день, час, точність і кількість натискань

### Гнучке налаштування

- Звуки клавіатури та звуки набору, регулюються гучність і швидкість мовлення
- Свої гарячі клавіші: повтор звуку (<kbd>Tab</kbd> / <kbd>F2</kbd>) і наступне слово (<kbd>Пробіл</kbd> / <kbd>Enter</kbd>)
- Екранна віртуальна клавіатура, світла / темна / системна тема
- **14 мов інтерфейсу**: інтерфейс слідує вашому вибору, а навчальний контент завжди китайський

### Чисто та ефективно

- Сучасний інтерфейс без реклами
- Працює повністю у браузері: без акаунта, без бекенда, без обовʼязкової реєстрації
- Весь прогрес зберігається локально у `localStorage`

### Словники

Вбудовані: **Повсякденні слова** (59), **Просунутий словник** (51), **Ідіоми з чотирьох ієрогліфів** (40).

Свій словник: вставте список або завантажте `.json` / `.csv` / `.txt`. Один запис на рядок, піньїнь будується автоматично:

```
中国,国家名称
旅行 lv you
安静=没有声音
```

Готовий приклад — `sample-words.csv`.

## Запуск локально

Проєкт зроблено на Next.js, потрібен Node.js 18 або новіший.

```bash
git clone https://github.com/CodeTrainerMan/typingchinese.git
cd typingchinese/web
npm install
npm run dev
```

Відкрийте <http://localhost:3000>.

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити dev-сервер |
| `npm run build` | Продакшен-збірка |
| `npm run start` | Запустити зібраний застосунок |
| `npm run lint` | ESLint |
| `npm run gen:dict` | Перестворити `public/dicts/*.json` з `scripts/seed-words.mjs` |

## Структура проєкту

```
web/                    Застосунок Next.js (єдиний блок для розгортання)
  src/app/              Маршрути: / (головна) /practice /article /dicts /wrong /stats /setting
  src/i18n/             Мовні пакети (додати мову: новий пакет + запис у LOCALES)
  src/lib/              Словники, піньїнь, TTS, планування FSRS, локальне сховище
  public/dicts/         Заздалегідь зібрані словники
  public/articles/      Вбудовані тексти для тренування
  scripts/              Початковий список слів і генератор словників
sample-words.csv        Приклад для імпорту власного словника
```

## Розгортання

У корені репозиторію немає `package.json`, тому під час імпорту проєкту у Vercel (або інший сервіс) **Root Directory має бути `web`**. Усе інше — стандартні налаштування Next.js.

## Пропозиції та внесок

Проєкт молодий, функції постійно додаються. Ідеї та повідомлення про помилки приймаються в `Issues`; якщо підхід вам близький, надсилайте `PR`.

- Додати мову: створіть пакет у `src/i18n/messages/` і зареєструйте його в `src/i18n/index.tsx`
- Додати слова: змініть `scripts/seed-words.mjs` і виконайте `npm run gen:dict`
