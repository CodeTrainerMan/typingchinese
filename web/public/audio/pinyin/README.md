拼音示范音 / Pinyin demo audio
==============================

共 67 个文件：单音 63 个（声母 23 + 韵母 24 + 整体认读 16）+ 四声示范 4 个。

## 1. 声母 / 韵母 / 整体认读（63 个）

按「拼音本体」命名：`b.mp3`、`ui.mp3`、`zhi.mp3`、`v.mp3`（ü 系列用 v 表示），
点一格听到的就是这个音本身，不是借来的某个字。

- 来源：汉语拼音网 <http://www.hanyupinyin.cn/> 的拼音发音表
  （音频基址 `http://du.hanyupinyin.cn/du/pinyin/`，声母韵母为 `<sym>.mp3`，
  整体认读为 `<sym>1.mp3`）
- 读法：声母是**呼读音**（`b` 读作「玻 bō」、`j` 读作「基 jī」），即汉语教学的通行读法
- 处理方式：按能量剖面（峰值 −32dB）定位发声段去首尾静音，
  highpass 100Hz + 响度归一到 −18 LUFS，输出 44.1kHz 单声道 MP3；时长 0.39–1.15s
- ⚠️ 该站点未声明开放许可。公开或商业用途请先自行取得授权。

其中 8 组音各有独立录音：`i/yi`、`u/wu`、`v/yu`、`ie/ye`、`ve/yue`、`in/yin`、
`ing/ying`、`vn/yun`；另外 7 组（`zh/zhi`、`ch/chi`、`sh/shi`、`r/ri`、`z/zi`、
`c/ci`、`s/si`）在源站本就是同一份录音——整体认读音节读的就是声母的呼读音。
