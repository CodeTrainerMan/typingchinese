拼音示范音 / Pinyin demo audio
==============================

## 1. 声母 / 韵母 / 整体认读标准发音（62 个）

按「拼音本体」命名：`b.mp3`、`ui.mp3`、`zhi.mp3`、`v.mp3`（ü 系列用 v 表示），
点一格听到的就是这个音本身，不是借来的某个字。

- 来源：普通话学习网「汉语拼音标准发音」 <http://www.pthxx.com/b_audio/08_pinyinfayin/>
- 处理方式：从站点的 Flash 发音文件（`audio_swf/*.swf`）中导出内嵌 MP3，
  去掉首尾静音后统一为 44.1kHz 单声道 MP3
- ⚠️ 该站点未声明开放许可。公开或商业用途请先自行取得授权。

## 2. 四声示范与 er（5 个）

`ma1.mp3` ~ `ma4.mp3`、`er2.mp3`

- 来源： <https://github.com/hugolpz/audio-cmn>（`64k/syllabs/`）
- 许可：**CC BY-SA**；录音者 **Chen Wang**（音节集 syllabs v.2），
  整理与压缩：Hugo Lopez（PLIDAM, INALCO）
- 原始命名 `cmn-{带调拼音}.mp3`，本站去掉 `cmn-` 前缀，内容未改动

部分格子共用同一份录音（如韵母 `in` 与整体认读 `yin`），这是有意的：它们同音。
